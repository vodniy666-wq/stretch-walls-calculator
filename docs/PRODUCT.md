# Продуктовое описание

## Назначение

«Стенограф» — мобильное адаптивное одностраничное веб-приложение для расчёта стоимости натяжных стен. Оно позволяет создать объект, разделить его на комнаты, добавить стены, настроить работы для каждой стены и получить итоговую площадь и стоимость.

## Иерархия данных и интерфейса

Основная иерархия расчёта:

**Объект → Комнаты → Стены.**

- Объект хранит название, необязательные данные клиента, комментарий, список комнат и дату обновления.
- Комната хранит название и список стен.
- Стена хранит название, ширину и высоту в миллиметрах, профили четырёх сторон, количества дополнительных элементов и настройки звукоизоляции.

На экране объекта комнаты представлены компактными карточками. На экране комнаты стены также представлены компактными карточками. Все параметры конкретной стены редактируются на отдельном экране стены.

## Текущая логика расчёта

Площадь стены в квадратных метрах рассчитывается автоматически: ширина в метрах умножается на высоту в метрах.

Профиль независимо выбирается для верхней, нижней, левой и правой сторон стены. Для верха и низа расчётной длиной является ширина стены, для левой и правой сторон — её высота. Стоимость стороны равна длине в метрах, умноженной на цену выбранного профиля за метр.

Дополнительные элементы рассчитываются по количеству: количество умножается на цену соответствующей позиции. Звукоизоляция рассчитывается по площади стены либо по площади, которую пользователь указал вручную, если включён этот режим.

Текущая итоговая стоимость стены складывается из профилей, дополнительных элементов и звукоизоляции. Итог комнаты является суммой показателей её стен, а итог объекта — суммой площади и стоимости его комнат.

Материал стены указан в продуктовых правилах как отдельная будущая группа стоимости, однако в текущей модели данных, прайсе, интерфейсе и расчётной функции выбор и стоимость материала ещё не реализованы. Это описание фиксирует фактическое состояние кода и не добавляет новую функциональность.

Некорректные, отсутствующие и отрицательные числовые значения расчётная функция приводит к безопасным неотрицательным значениям. При редактировании интерфейс сохраняет ширину и высоту не меньше одного миллиметра, а количества и вручную заданную площадь — не меньше нуля.

## Существующие элементы

В MVP доступны:

- профили отдельно для каждой из четырёх сторон;
- подрозетники / выключатели;
- внутренние углы;
- внешние углы;
- звукоизоляция для полной площади стены или площади, заданной вручную.

Новые стены создаются с размерами 4200 × 2700 мм, угловым профилем сверху, слева и справа, отбойником снизу, нулевым количеством дополнительных элементов и выключенной звукоизоляцией.

## Структура прайса

Единственный источник цен — `data/prices.json`. Это JSON-массив позиций со следующими полями:

- `id` — стабильный идентификатор, по которому расчёт и сохранённые данные ссылаются на позицию;
- `category` — категория позиции (`profile`, `extra` или `soundproof` в текущем прайсе);
- `name` — отображаемое название;
- `unit` — единица измерения;
- `price` — цена за единицу.

Текущий прайс содержит три профиля, три дополнительных элемента и звукоизоляцию. После загрузки приложения массив преобразуется в справочник по `id`; расчёт получает цены из этого справочника. Названия профилей на чертеже также берутся из прайса.

## Чертёж стены

На экране редактирования отображается схематичный фронтальный вид стены. Чертёж:

- сохраняет соотношение ширины и высоты в пределах размеров области отображения;
- показывает ширину и высоту в миллиметрах;
- отображает отдельную линию профиля на каждой стороне;
- показывает в легенде выбранный профиль каждой стороны, получая его название из прайса;
- обозначает отсутствие профиля.

Дополнительные элементы на чертеже пока не отображаются. Чертёж не является CAD-редактором и пока не поддерживает координаты или ручное размещение элементов.

## Хранение данных

Проекты сохраняются в `localStorage` браузера под ключом `stenograf-projects-v1`. Изменения записываются на текущем устройстве; серверная база данных, синхронизация между устройствами и авторизация отсутствуют. Пользователь может открывать, копировать и удалять сохранённые расчёты.

## Публикация

Приложение предназначено для публикации через GitHub Pages из репозитория `stretch-walls-calculator`, то есть может работать в подпапке `/stretch-walls-calculator/`. Статические ресурсы подключаются относительными путями, а прайс загружается через URL относительно JavaScript-модуля, чтобы развёртывание в подпапке не ломало приложение.

## Будущие функции — сейчас не реализовывать

Следующие возможности относятся к будущему развитию продукта и не должны добавляться без отдельного прямого запроса пользователя:

- градации цен;
- роли пользователей;
- административная панель;
- формирование PDF;
- отправка предложения клиенту;
- ручное позиционирование подрозетников, выключателей и других элементов на чертеже.
