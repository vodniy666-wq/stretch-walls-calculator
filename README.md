# Стенограф — калькулятор натяжных стен

Адаптивное одностраничное приложение для расчёта натяжных стен. Данные расчётов сохраняются локально в браузере, а цены загружаются из отдельного JSON-файла.

## Запуск

```bash
npm start
```

Откройте <http://localhost:4173>. Тесты расчётной логики запускаются командой `npm test`.

## Возможности MVP

- иерархия «объект → комнаты → стены» без перегруженных форм;
- материал по площади, профили отдельно для каждой стороны, дополнительные элементы и звукоизоляция;
- автоматический расчёт стены, комнаты и объекта;
- пропорциональный эскиз стены с обозначением подрозетников / выключателей;
- сохранение, копирование, открытие и удаление расчётов через `localStorage`;
- отдельный экран прайса; цены из `data/prices.json`.
